# Hardware reference

Основная схема: [20150722_hoverboard_sch.pdf](20150722_hoverboard_sch.pdf).

- Лист 1/13: два отдельных моторных канала LEFT_MOTOR и RIGHT_MOTOR, по три фазы, отдельные цепи шунтов/измерения.
- Лист 8/13 (страница PDF 3): MCU STM32F103RCT6 и управляющие сигналы двух инверторов.
- Лист 11/13 (страница PDF 6): разъёмы и сигнальные линии.
- Лист 12/13 (страница PDF 7): узлы питания, включая 7805 (+5 В) и стабилизатор +3,3 В.

Важно: обозначения схемы являются исходной аппаратной документацией, но не заменяют прозвонку и измерения конкретной платы. До назначения входов газа/тормоза сверить ревизию платы, разъём, уровень сигнала и назначение ножки MCU.
